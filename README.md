Power BI Business Intelligence Training MIS 561, September 28, 2026, [and a link to your published Tableau story](https://public.tableau.com/views/PowerBITrainingCertifications_17906618893050/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link), One thing I liked about Power BI is how easy it is to separate data within the same column. For example, if names or other information are separated by an underscore (_), Power BI can create a new column by splitting the data using the underscore as the delimiter. In Excel or Tableau, I had to do more of this data cleaning manually. Next time, I would choose Power BI for this task because it makes separating and organizing data faster and easier.

Introduction to DAX in Power BI MIS 561, October 5, 2026, [and a link to your published Tableau story](https://public.tableau.com/views/PowerBITrainingCertifications_17906618893050/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)], I calculated the order delivery duration using the formula (Order2Delivery = DATEDIFF(Sales[OrderDate], Sales[DeliveryDueDate], DAY)), which takes each order’s Order Date as the starting date, Delivery Due Date as the ending date, and returns the difference between them in days. In Power BI, I would build this as a calculated column rather than a measure because the date difference is a fixed property of each individual order that must be calculated row by row before any averaging or summarizing occurs. By putting this calculation directly in the data model, Anita can filter, slice, or average delivery timelines across any region or product line. This allows Anita to analyze delivery performance herself without asking the BI team to manually recalculate shipping durations in static workbooks.

Advancing in Power BI for Data Visualization MIS 561, October 12, 2026, [and a link to your published Tableau story](https://public.tableau.com/views/PowerBITrainingCertifications_17906618893050/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link), My experience with business intelligence tools has prepared me to analyze data, identify trends, and communicate findings that support business decisions. For example, in Flex 4, I created a Tableau scatter plot comparing total revenue and net contribution across 794 customer accounts. I identified more than 220 accounts receiving discounts above 20% while generating negative profits. Rebuilding this analysis in Power BI using an interactive scatter plot and conditional formatting in a matrix would help management identify accounts that may require changes to their discounting strategies. Additionally, in Flex 6, I used the DATEDIFF function in Power BI to create a calculated column measuring the days between order dates and delivery due dates. Incorporating this calculation into interactive reports would allow management to compare delivery timelines across orders and identify areas requiring further investigation. I recognize that each tool has different strengths. I would use Excel for quick calculations, data cleaning, and preliminary analysis. Tableau would be useful when presenting a focused visualization to communicate a specific finding. I would choose Power BI when multiple departments need interactive dashboards that integrate data sources and monitor performance over time. However, I still need experience publishing reports through Power BI Service and maintaining dashboards for other users. I plan to develop these skills by practicing report publishing, scheduled data refreshes, and access management using sample business datasets.
