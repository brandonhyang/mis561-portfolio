Power BI Business Intelligence Training MIS 561, September 28, 2026, a, [and a link to your published Tableau story](https://public.tableau.com/views/PowerBITrainingCertifications_17906618893050/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link), One thing I liked about Power BI is how easy it is to separate data within the same column. For example, if names or other information are separated by an underscore (_), Power BI can create a new column by splitting the data using the underscore as the delimiter. In Excel or Tableau, I had to do more of this data cleaning manually. Next time, I would choose Power BI for this task because it makes separating and organizing data faster and easier.

Introduction to DAX in Power BI MIS 561, October 5, 2026,[a link to your published Tableau workbook](https://public.tableau.com/views/PowerBITrainingCertifications_17906618893050/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)], I calculated the order delivery duration using the formula (Order2Delivery = DATEDIFF(Sales[OrderDate], Sales[DeliveryDueDate], DAY)), which takes each order’s Order Date as the starting date, Delivery Due Date as the ending date, and returns the difference between them in days. In Power BI, I would build this as a calculated column rather than a measure because the date difference is a fixed property of each individual order that must be calculated row by row before any averaging or summarizing occurs. By putting this calculation directly in the data model, Anita can filter, slice, or average delivery timelines across any region or product line. This allows Anita to analyze delivery performance herself without asking the BI team to manually recalculate shipping durations in static workbooks.
